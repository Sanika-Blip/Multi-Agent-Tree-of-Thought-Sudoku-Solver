Multi-agent Tree-of-Thought Sudoku solver

A 4×4 puzzle, solved in the browser by a supervisor and three specialist agents. Press play and watch guesses get checked, pruned, and undone. The graded runs used a local Qwen model; this page uses the same agent loop with a fixed weak proposer so it works without installing anything.

Short-term memory

A checkpoint after every hop lets a stopped search resume on the same thread.

Long-term memory

Proven dead ends are stored and survive a restart of the program.

Retrieval

Ten short Sudoku notes are indexed. The proposer reads one before it guesses.

Guard

Switch the rule checker off above. Illegal digits stay on the board and the solve fails.
